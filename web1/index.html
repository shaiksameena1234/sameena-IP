CSS Animation Basics

Every animation here uses the same recipe: define a @keyframes block describing the states, then attach it to an element with the animation shorthand (duration, timing-function, iteration-count, direction). The last card shows transition instead, which is simpler and only needs a trigger like :hover.

1. Move + Color change

animation: moveColor 2s ease-in-out infinite alternate;

2. Spinner / Loader

animation: spin 1s linear infinite;

3. Pulse

animation: pulse 1.2s ease-in-out infinite;

4. Bounce

animation: bounce 1s cubic-bezier(...) infinite;

5. Hover transition (hover me)

transition: opacity 0.5s, transform 0.5s; on :hover

6. Sliding text

Hello, I'm sliding! →

animation: slide 4s linear infinite;
